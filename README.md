# 🚨 Emergency Resource Allocation System

## About the Project
The Emergency Resource Allocation System is a C++ based project using Data Structures and Algorithms (DSA). It helps manage emergency situations by providing resources like ambulances, food, water, and medicines.

## Objectives
- Manage emergency requests.
- Give priority to serious emergencies.
- Allocate available resources.
- Save emergency records using file handling.

## Technologies Used
- Programming Language: C++
- Data Structures and Algorithms (DSA)
- File Handling

## DSA Concepts Used
- Queue
- Priority Queue
- Array
- Linked List
- Graph

## How Does the Project Work?
First, the user enters an emergency request with the location and required resources. The system checks the priority of the emergency and handles the most serious request first. Then, it checks the available resources and allocates them to the emergency location. Finally, the system updates the remaining resources and saves the emergency details in a file for future use.

## Conclusion
This project helps us understand how C++ and DSA can be used to manage emergencies and distribute resources efficiently.
